# MTH321 Project 1 — Numerical Solution of the Robertson Stiff ODE Problem

## Overview

This repository contains the numerical implementation and reproducibility files for **MTH321 Project 1: Numerical Solution of ODE Initial Value Problems**.

The project studies the **Robertson chemical kinetics problem**, a classical stiff system of ordinary differential equations.

The Robertson system is:

- `y1' = -0.04 y1 + 10^4 y2 y3`
- `y2' = 0.04 y1 - 10^4 y2 y3 - 3×10^7 y2^2`
- `y3' = 3×10^7 y2^2`

with the initial condition:

`y(0) = (1, 0, 0)`

over the time interval:

`0 <= t <= 40`

The main objective is to compare explicit and implicit numerical methods for this stiff problem and validate their accuracy, stability, physical behaviour, and computational cost.

---

## Numerical Methods

The project implements and investigates:

- Explicit Euler
- Classical fourth-order Runge–Kutta (RK4)
- Implicit Euler
- Trapezoidal / Crank–Nicolson method
- Adaptive Explicit Euler with step-size control

The nonlinear systems arising from the implicit methods are solved using Newton iteration.

A high-accuracy implicit SciPy solution is used as the numerical reference for validation.

## Reference Solution

A high-accuracy implicit solver from `scipy.integrate.solve_ivp` is used to construct the reference trajectory.

The reference solution is computed using tight numerical tolerances and is used as the numerical ground truth for error calculations and validation experiments.

Reference consistency is also checked through tolerance refinement and independent numerical diagnostics.

---

## Validation and Sanity Checks

Several independent diagnostics are used to verify that the numerical implementation behaves consistently with the mathematical and physical properties of the Robertson problem.

### Conservation

The Robertson system satisfies the linear invariant:

`y1 + y2 + y3 = 1`

The conservation defect is monitored throughout the numerical integration.

A small conservation defect alone is not treated as sufficient evidence of an accurate solution, so conservation is considered together with non-negativity and full-state error.

### Non-negativity

Because the state variables represent chemical species concentrations, physically meaningful solutions should satisfy:

`yi(t) >= 0`

Minimum component values and negative-value counts are monitored during the numerical experiments.

### Convergence

Uniform-step convergence studies use successively refined step sizes.

The numerical solutions are compared with the high-accuracy reference solution, and the observed convergence orders are estimated from the resulting errors.

### Stability and Stiffness

The Jacobian eigenvalues are analysed to characterise the stiffness of the Robertson problem.

The numerical stability behaviour of the explicit methods is compared with the step-size restriction suggested by the Jacobian eigenvalues.

Empirical step-size experiments are also used because the frozen-Jacobian estimate is only a local stability diagnostic.

### Newton Iteration

The nonlinear equations in the implicit methods are solved using Newton iteration.

Tolerance-sensitivity experiments are used to verify that the nonlinear-solver error is sufficiently small relative to the time-discretisation error.

### Adaptive Step Size

The adaptive Euler implementation changes the step size according to a local error estimate.

Accepted and rejected steps are recorded to demonstrate the behaviour of the adaptive controller.

### Transient Behaviour

The second component, `y2`, undergoes a rapid early transient.

Its behaviour is checked to ensure that it relaxes after its early maximum without spurious numerical oscillations and that the computed solution remains physically meaningful.

---

## Error Measures

The main error measure used for full-trajectory comparisons is the maximum Euclidean state error over the integration interval.

In notation used in the report:

```text
E_inf(h) = max over 0 <= t <= 40 of || y_h(t) - y_ref(t) ||_2
```

where:

- `y_h(t)` is the numerical solution obtained with step size `h`;
- `y_ref(t)` is the high-accuracy reference solution;
- `|| . ||_2` denotes the Euclidean norm.

Final-time error and other diagnostic quantities are reported separately where appropriate.

---

## Computational Cost

Computational cost is evaluated together with numerical accuracy.

Depending on the experiment, the recorded work measures include:

- number of time steps;
- Newton iterations;
- accepted and rejected adaptive steps;
- wall-clock runtime.

Wall-clock measurements depend on the machine, Python environment, and implementation details. They should therefore be interpreted together with numerical error and algorithmic work rather than as standalone performance measures.

Setup, plotting, LaTeX compilation, and other non-time-stepping operations are not treated as numerical integration costs unless explicitly stated.
